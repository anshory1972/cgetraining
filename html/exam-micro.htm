Question 1

In the CES production function Q = {Σi δiXi−ρ}−1/ρ, the elasticity of substitution σ is:

Not answered.

σ = 1/(1+ρ), so with −1 < ρ < ∞ we get 0 < σ < ∞. CES slides, "Elasticity of substitution"; Handout #1, eq. (8).
Question 2

Which special case of the CES production function is matched correctly?

Not answered.

Cobb-Douglas is the CES limit at σ = 1; Leontief at σ = 0; the linear (perfect-substitutes) function at σ = ∞. "Special cases of CES production function" slide.
Question 3

A firm has CES technology with σ = 0.5. If the factor-price ratio w/r rises by 2 percent, the factor intensity K/L will:

Not answered.

K/L = (δK w / δL r)σ: a 1% rise in the price ratio raises intensity by σ%, so 2% × 0.5 = 1%. "Factor intensity and factor price ratio" slide.
Question 4

Under Leontief technology the cost-minimizing input demand is Xi = AiQ. Why does it not respond to input prices?

Not answered.

With right-angle isoquants the optimum is always at the kink, whatever the isocost slope: σ = 0. CRS explains proportionality to Q, not price independence. "Leontief production function is input-price independent" slide.
Question 5

Cost minimization with CES technology gives the demand for input i. Which formula is correct?

Not answered.

Demand is proportional to output and decreasing in the input’s price relative to unit cost c — not relative to another input’s price. Option (d) is the Cobb-Douglas consumer demand. Handout #1, eq. (9); "Demand for factors and unit cost" slide.
Question 6

The unit cost of production under CES technology is:

Not answered.

The CES unit-cost (price) index is c = (Σ δiσWi1−σ)1/(1−σ); total cost is then C = cQ. Handout #1, eq. (10).
Question 7

With CES technology, total cost is C = cQ, so average cost is constant and does not depend on Q. This is because:

Not answered.

Under CRS, scaling output scales all inputs proportionally at unchanged input mix, so cost per unit is unchanged — the answer to the slides’ query "why is average cost constant, shouldn’t it be U-shaped?" Handout #1, eq. (7); "Demand for factors and unit cost" slide.
Question 8

In the derivation of CES input demand, taking the ratio of two first-order conditions serves to:

Not answered.

λ appears multiplicatively in every FOC, so dividing one FOC by another cancels it, leaving Wi/Wj = (δi/δj)(Xi/Xj)−ρ−1. Handout #1, eq. (3).
Question 9

The CES cost share of input j is Sj = δjσWj1−σ / Σi δiσWi1−σ. When σ = 1 (Cobb-Douglas), the cost share of input j becomes:

Not answered.

At σ = 1 the price terms drop out (W1−σ = W0 = 1) and Σδi = 1, so Sj = δj: constant cost shares are the Cobb-Douglas signature. Handout #1, "Cost share with σ".
Question 10

The nested production function Q = f(L, K) with composite labor L = g(U, S) can be solved as two separate cost-minimization problems because:

Not answered.

Separability lets you first find the cheapest U,S mix for any L, then treat L as an ordinary input; the nests may have different elasticities. "Nested production function" and "Cost minimization with nested production function" slides.
Question 11

In the upper-nest problem min wL + rK, the price w of composite labor is:

Not answered.

w = (δU1/(1+ρL)wUρL/(1+ρL) + δS1/(1+ρL)wSρL/(1+ρL))(1+ρL)/ρL — the lower nest’s unit cost carried up as the composite’s price. "Solution to problem #1", eq. (3).
Question 12

Which of the following is NOT a property of the Cobb-Douglas demand system Xi = αiY/Pi?

Not answered.

Cross-price elasticities are exactly zero: the demand for good i depends only on Y and its own price. That restrictiveness motivates Stone-Geary. "Cobb-Douglas Demand System" slide.
Question 13

In the Stone-Geary utility function U = Πi(Xi − γi)βi, the parameter γi is:

Not answered.

γi is subsistence consumption; Xi − γi is supernumerary consumption, and βi (which sums to 1) is the marginal budget share. "Stone-Geary utility function" slide; Handout #2.
Question 14

Under the LES, the income elasticity of good i is ηi = βi/wi, where wi is its budget share. If βi = 0.1 and wi = 0.25, good i is:

Not answered.

η = 0.1/0.25 = 0.4 < 1: a necessity. Its budget share falls as income rises — the Engel behavior Cobb-Douglas cannot produce. "Some features of the LES demand function" slide.
Question 15

If every subsistence parameter is zero (γi = 0 for all i), the LES demand system Xi = γi + (βi/Pi)(Y − ΣjPjγj) collapses to:

Not answered.

With all γ = 0, supernumerary income equals Y and Xi = βiY/Pi — Cobb-Douglas, with β as constant budget shares. "Stone-Geary utility function" slide; Handout #2.
